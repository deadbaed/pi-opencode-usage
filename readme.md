# pi-opencode-usage

Pi extension to check OpenCode Go usage. It can also emit events so other extensions can do something with that information (for example show in a footer).

## Example

```shell
$ pi

 █▀ █ escape interrupt · ctrl+c/ctrl+d clear/exit · / commands · ! bash · ctrl+o more
 Press ctrl+o to show full startup help and loaded resources.
```

## Features

- Reads the active OpenCode Go API key from Pi's runtime auth.
- Sends credentials only to the official `https://opencode.ai` origin.
- Caches usage for 5 minutes with background refresh.
- Configurable: `compact`, `regular`, or `plain` style (`regular` by default). The settings are stored in `pi-opencode-usage.json` in your pi folder.
- Integrates with any footer that reads `ctx.ui.setStatus()` values, for example I use [pi-footer](https://github.com/wobondar/pi-footer), so I want to have it in my footer.

## Install

With NodeJS installed (I tested with NodeJS 24):

```shell
pi install https://github.com/deadbaed/pi-opencode-usage
```

## Usage

Once activated, the extension will work only when using models from `opencode-go`.

Commands:

- `/opencode-usage` — manually refresh usage
- `/opencode-usage style` — cycle through styles, save new style in the settings file

### Styles

- **regular** (default): `opencode rolling:1% ↻ 4h33m · weekly:25% ↻ 1d8h · monthly:12% ↻ 29d4h`
- **compact**: `opencode r:1% ↻ 4h32m · w:25% ↻ 1d8h · m:12% ↻ 29d4h`
- **plain**: `opencode 1% ↻ 4h32m · 25% ↻ 1d8h · 12% ↻ 29d4h`

The selected style is stored in `~/.pi/agent/pi-opencode-usage.json`.

### Integration with `pi-footer`

I use [pi-footer](https://github.com/wobondar/pi-footer) as my footer. When customizing the footer (with `/footer` inside pi), you can add the `Extension Status` widget in your lines. The usage status will be shown automatically.
